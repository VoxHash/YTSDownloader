# Support

## Getting Help

- Documentation: [docs/index.md](docs/index.md)
- Bug reports: [GitHub Issues](https://github.com/VoxHash/YTSDownloader/issues)
- Feature requests: use the Feature request issue template
- Security reports: see [SECURITY.md](SECURITY.md)

## Before Opening an Issue

1. Confirm `ffmpeg` is installed (`ffmpeg -version`).
2. Confirm dependencies install with `pip install -r requirements.txt`.
3. Check `config.ini` authentication settings if YouTube/Instagram fail with
   bot or login errors.
4. Include OS, Python version, and relevant log output from the app Logs panel.
